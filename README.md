# Vivek Portfolio - COMP229 Assignment 1

Personal portfolio website created with React for COMP229 Web Application Development.

## Pages
- Home
- About Me
- Projects
- Education
- Services
- Contact Me

## Technologies
- React
- React Router
- JavaScript
- HTML / JSX
- CSS
- Vite

## Run Locally
1. Open the project folder in your IDE.
2. Open a terminal in the project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

## Build
Run `npm run build` to create a production build.
